已核对的 writer 为 `0.167.0-alpha.4.1`、`0.169.0-alpha.11.1`、`0.169.1`、`0.171.0-alpha.13` 与 `0.171.0-alpha.13.2`。在 `0.169.0-alpha.11.1` 与 `0.171.0-alpha.13` 的原生记录中均观察到桌面注入的页面上下文。适配器按 `agent` 命名空间、已验证的记录名称、缺省调用 ID 和文本输出识别这些记录，逐条保留文本并记录降级。未知 writer 的诊断包含实际版本号。回归样本独立重建。

2026-11-26 在 Windows 的 `0.171.0-alpha.13.2` CLI 上核对了新建及恢复后的双轮 JSONL 会话。四条对话原文和顺序一致，源文件哈希保持一致；转入 Claude Code 2.1.121 后，另起目标进程用目标会话 ID 取回了两轮回执。[原生回归](../../../tools/m31/native-handoffs.mjs)

转换层读取 message、函数与自定义工具调用及结果、可读 reasoning、原始指令、turn_context、compacted 和回退标记。存在结构化 UserMessage 时，桌面对话页使用原生时间线，并按轮次和调用 ID 补入底层记录中的工具返回、推理摘要和来源。可展开已有文件补丁、计划、命令及失败正文。原始记录和字段随包保留；未知语义内容与加密 reasoning 按损耗策略处理。工具引用损坏、截断行或缺失必需附件会产生诊断。

Zstd 回归样本使用标准 raw-block frame；解码使用 fzstd，不依赖本机压缩程序。压缩前后 CSR 正文等价，归档保持输入原始字节。
